# Kukiku Tejidos 🧶

Proyecto web para el catálogo de tejidos artesanales "Kukiku".
Construido con React (Frontend) y Node.js + Express (Backend).

## Estructura del Proyecto
- `/backend`: API en Node.js que sirve el catálogo de productos.
- `/frontend`: Aplicación en React para la interfaz de usuario.

## Cómo correr el Backend
1. Ir a la carpeta: `cd backend`
2. Instalar dependencias: `npm install`
3. Iniciar el servidor: `node server.js`

## Cómo correr el frontend
1. Ir a la carpeta `cd frontend`
2. iniciar el servidor: `npm run dev`
